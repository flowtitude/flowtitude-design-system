2. Escala fluida tecnica

Estos tokens son la escala base. Los espacios semanticos se derivan de ellos.

--spacing-fluid-xs
--spacing-fluid-sm
--spacing-fluid-md
--spacing-fluid-lg
--spacing-fluid-xl
--spacing-fluid-2xl

3. Espacios semanticos

La misma idea se puede usar como padding, gap, margin o space-y.

inner

p-inner / gap-inner / space-y-inner

content

p-content / gap-content / space-y-content

stack

p-stack / gap-stack / space-y-stack

block

p-block / gap-block / space-y-block

columns

p-columns / gap-columns / space-y-columns

section

p-section / py-section / gap-section

hero

p-hero / py-hero / gap-hero

4. Clases por familia

El token es el mismo; cambia el prefijo de utilidad.

Padding

p-block, px-block, py-block, pt-block, pb-block

Gap

gap-block, gap-x-columns, gap-y-stack

Stack

space-y-block separa hijos verticales sin tocar cada hijo.

5. Secciones reales

Las secciones consumen --ft-padding-content-y, --ft-padding-content-y-half y los tokens semanticos.

section normal

Padding contextual por defecto

La primera seccion de main recibe mas aire superior.

has-background

Padding vertical completo

Una banda con fondo necesita respirar mas.

half-top half-bottom

Seccion compactada manualmente

Util cuando el contexto necesita menos aire vertical.
