.bg-image

Imagen de fondo full-cover con z-index negativo. Para usar dentro de secciones con contenido encima.

<section class="relative has-background"> <img src="hero.jpg" class="bg-image" alt=""> <div> <div> <h1>Contenido sobre la imagen</h1> </div> </div> </section> <!-- .bg-image aplica: absolute inset-0 size-full object-cover -z-1 -->

.click-parent

Hace todo el contenedor clickeable via un pseudo-elemento ::after que cubre el area completa.

<div class="click-parent relative"> <a href="/destino">Link interno</a> <p>Todo el bloque es clickeable</p> </div>

.focus-from-child

El contenedor recibe estilo visual cuando un hijo tiene focus. Ideal para cards con links internos.

<div class="focus-from-child"> <input type="text" placeholder="Al hacer focus aqui..."> <p>...todo el contenedor recibe shadow + border</p> </div>

Custom Variants

Variantes de Tailwind definidas en main.css para estilar basandose en el padre.

/* Definicion (main.css) */ @custom-variant parent (*:has(> &)); @custom-variant parent-hover (*:hover > &); @custom-variant parent-focus-within (*:focus-within > &); /* Uso en HTML */ <div> <!-- padre --> <span class="parent:text-red-500"> Rojo si es hijo directo </span> <span class="parent-hover:scale-110"> Escala cuando hover en el padre </span> </div>
