Auditoria por Leccion

L1 La filosofia Flowtitude OK
Sin problemas Leccion conceptual sin referencias tecnicas al codigo. No requiere cambios.
L2 Descarga e instalacion en WindPress 4 issues
Faltante Layer custom omitido El curso muestra @layer theme, base, layouts, components, utilities; pero el codigo real tiene 6 layers: @layer theme, base, layouts, components, utilities, custom;
Faltante Imports incompletos en main.css Faltan en el listado: components/typography.css (clases .display, .heading, etc.), components/custom.css (.eyebrow) y wizard.css. El alumno no sabe que existen.
Menor Custom variants no mencionadas El main.css real incluye @custom-variant parent, parent-hover y parent-focus-within al final. Aunque se cubren en L6, el indice de main.css deberia mencionarlas.
Menor Nombre del archivo de descarga El curso dice fds-core.windpress. Verificar que el archivo real se llame exactamente asi.
L3 El archivo de configuracion flowtitude.css 1 error + 3 faltantes
Error Valor de --ft-color-background incorrecto El curso dice --ft-color-background: #fff; pero el codigo real tiene --ft-color-background: #f9ecec;. Contradice ademas la verificacion de L2 que dice "el fondo no es blanco puro".
Faltante Knobs de spacing no documentados La leccion omite completamente las variables de spacing: --ft-space-min/max, --ft-space-step-min/max, --ft-space-factor y los 7 multiplicadores semanticos (--ft-space-factor-inner a --ft-space-factor-hero). Estas son cruciales para entender el sistema.
Faltante Tokens adicionales no mencionados No se documentan: card widths (--ft-card-xs a --ft-card-xl), button variables (--btn-py/px, colores), leading, radius ni aspect ratios. El alumno no sabe que puede configurarlos.
Faltante Factor global de escala Menciona --ft-space-factor en L7 ("cambia de 1 a 0.8") pero nunca lo introduce en L3 junto al resto de knobs. Deberia presentarse aqui primero.
L4 El sistema tipografico integral 2 errores + 1 faltante
Error Nombres de clases .text-* incorrectos El curso dice .text-lead, .text-caption y .text-body. Estas clases NO existen en el codigo. Los nombres reales son: .text-large (lg), .text-small (sm) y .text-medium (base).
Error Descripcion de subheadings incorrecta El curso dice que los subheadings "suelen usar mayusculas (uppercase), tracking amplio y colores de acento". El codigo real aplica font-semibold leading-none text-pretty — sin uppercase, sin tracking especial, sin colores de acento.
Faltante Alias .display-single y blockquote incompleto No menciona el alias .display-single (= display-sm). El blockquote de .prose muestra solo 3 propiedades pero el real tambien tiene text-secondary-700 my-4.
L5 Layout basico y estructural OK
Preciso y correcto La logica de secciones (.has-background, .half-top/bottom, .block-bleed) coincide con el codigo. Content-flex con sus 9 posiciones es correcto. La tabla de clases es precisa.
L6 Utilidades de grid avanzadas y la variacion parent OK (2 menores)
Contenido correcto auto-fit/fill, card sizes y grids asimetricos coinciden con el codigo. Custom variants correctas.
Menor Grids mostrados son un subconjunto El codigo tiene 30+ utilidades de grid pero el curso solo muestra ~8. Aceptable para ensenanza, pero podria mencionarse que hay mas disponibles.
Menor parent-focus-within sin ejemplo Se explica parent y parent-hover pero parent-focus-within solo se menciona al pasar. Un ejemplo de uso en formularios seria util.
L7 Extendiendo el sistema OK
Correcto La metodologia de extension (crear archivo, importar en main.css, usar custom.css) es precisa. El ejemplo de @apply en componentes es valido.
