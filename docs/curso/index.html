L1 La filosofia Flowtitude

1. El Problema: La Fatiga de Decision

Cada vez que inicias un proyecto desde cero, te enfrentas a un lienzo en blanco que exige cientos de micro-decisiones:

  • Nomenclatura de clases de estructura
  • Escala tipografica
  • Gestion de espaciados en movil

2. El Objetivo: Estandarizacion y Paz Mental

  • Centralizas el control: La configuracion siempre vive en flowtitude.css
  • Eliminas la duda: Arquitectura validada, sin inventar nombres
  • Ganas seguridad: Cimientos matematicamente solidos

3. La Ventaja Competitiva

  1. Cura la "Panelitis": Dejas de depender de pestanas y menus de Bricks
  2. Arranca mas rapido: Salta la configuracion
  3. Escala mejor: Cambios globales desde una variable
  4. Mantiene la calidad: Consistencia garantizada por el sistema
L2 Descarga e instalacion en WindPress

1. Anatomia del Sistema

El archivo principal (main.css) actua como indice:

FALTANTE: La declaracion de layers real tiene 6 capas (custom incluido), no 5. Ademas faltan components/typography.css, components/custom.css y wizard.css en el listado de imports.
main.css 
/* main.css - El cerebro de operaciones */
@layer theme, base, layouts, components, utilities;

/* 1. CONFIGURACION */
@import './theme/flowtitude.css';

/* 2. CIMIENTOS */
@import './base/base.css';
@import './base/typography.css';

/* 3. ESTRUCTURA */
@import './layouts/section.css';
@import './layouts/content-flex.css';

/* 4. ELEMENTOS UI */
@import './components/buttons.css';
@import './components/components.css';

/* 5. UTILIDADES */
@import './utility/core/utilities.css';
@import './utility/animations/durations.css';
@import './utility/layout/grid-basic.css';

2. Pasos de Instalacion

  1. Descarga el archivo fds-core.windpress
  2. Importa en WordPress > WindPress > Import
  3. Verifica: Anade una Seccion en Bricks — debe tener padding automatico y fondo no blanco puro
ADVERTENCIA: La importacion recreara toda la estructura CSS en WindPress. En webs existentes, exporta tu configuracion antes de importar.

2. Configuracion global: fondo y texto

ERROR: El curso dice --ft-color-background: #fff pero el valor real en el codigo es --ft-color-background: #f9ecec. Corregir en el texto.
CSS 
--ft-color-text: #000;
--ft-color-background: #fff;  /* ERROR: real = #f9ecec */

Colores definidos en OKLCH. Recomendacion: usar tints.dev para generar escalas profesionales.

L4 El sistema tipografico integral

1. Preflight semantico (base/typography.css)

base/typography.css 
h1, h2, h3, h4, h5, h6 {
  @apply break-words font-display font-bold text-balance tracking-tight;
}

h1 { @apply text-5xl leading-none tracking-wider; }
/* h2: text-4xl, h3: text-3xl, h4: text-2xl, h5: text-xl, h6: text-lg */

2. El componente .prose

Wrapper inteligente para contenido editorial. Gestiona ritmo vertical, selectores de adyacencia y elementos ricos automaticamente.

3. Clases semanticas (components/typography.css)

ERROR: El curso menciona .text-lead, .text-caption y .text-body. Estas clases NO EXISTEN. Los nombres reales son: .text-large, .text-small y .text-medium.

L5 Layout basico y estructural

1. El patron "seccion inteligente" (section.css)

  • Default: Medio padding (py / 2) — dos secciones apiladas suman 1 unidad completa
  • .has-background: Padding completo + fuerza padding en secciones adyacentes
  • .half-top / .half-bottom: Fuerza medio padding manual
  • .block-bleed: Elemento hijo ocupa 100vw

2. Content-flex (content-flex.css)

9 posiciones con una sola clase. Default: centrado. Gestiona flex, texto y margenes a la vez.

L6 Utilidades de grid avanzadas y la variacion parent

1. Grids automaticos (auto-fit y auto-fill)

ClaseMin. tarjetaUso
.grid-auto-fit-xs12rem (192px)Iconos, logos
.grid-auto-fit-sm14rem (224px)Listados densos
.grid-auto-fit-md18rem (288px)Blog, productos
.grid-auto-fit-lg24rem (384px)Tarjetas destacadas
.grid-auto-fit-xl36rem (576px)2 columnas grandes

2. Grids asimetricos

La asimetria se define en el padre. Los hijos se colocan automaticamente.

  • .grid-cols-1-2 / .grid-cols-2-1 — 33%/67%
  • .grid-cols-1-3 / .grid-cols-3-1 — 25%/75%
  • .grid-cols-1-2-1 — Centrado optico
  • .grid-cols-2-3 — 40%/60%

El codigo incluye 30+ variaciones de grid. Consultar docs/layouts para la referencia completa.

3. La variante parent

CSS 
@custom-variant parent (*:has(> &));
@custom-variant parent-hover (*:hover > &);
@custom-variant parent-focus-within (*:focus-within > &);

Permite estilizar un hijo basandose en el estado del padre directo sin tocar el padre.

L7 Extendiendo el sistema

1. Modificar Defaults

Cambiar --ft-space-factor de 1 a 0.8 reduce todo el spacing proporcionalmente.

2. Crear componentes propios

  1. Crear archivo en components/ (ej: product-card.css)
  2. Definir con @apply para componer utilities
  3. Importar en main.css en la seccion de componentes

3. custom.css para estilos rapidos

Para clases pequenas que no merecen archivo propio.

4. Actualizaciones

Los cambios del sistema reemplazan archivos base. Tus personalizaciones (custom.css, archivos propios, flowtitude.css) se mantienen intactas.
