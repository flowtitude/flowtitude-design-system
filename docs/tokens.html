Escala tipografica

Generada desde --ft-type-step-min: 1.125 / --ft-type-step-max: 1.2

--text-base → calc(clamp(1rem ... 1.125rem) * factor) --text-sm → base / step --text-xs → sm / step --text-lg → base * step --text-xl → lg * step ...continua hasta --text-9xl

Referencia de knobs

/* Viewport */ --viewport-min: 410px; --viewport-max: 1280px; /* Typography */ --ft-text-min: 1rem; --ft-text-max: 1.125rem; --ft-type-step-min: 1.125; --ft-type-step-max: 1.2; --ft-text-factor: 1; /* Spacing */ --ft-space-min: 0.5rem; --ft-space-max: 1.5rem; --ft-space-step-min: 1.3; --ft-space-step-max: 1.5; --ft-space-factor: 1; /* Semantic multipliers */ --ft-space-factor-inner: 0.5; --ft-space-factor-content: 0.75; --ft-space-factor-stack: 1; --ft-space-factor-block: 1; --ft-space-factor-columns: 1.5; --ft-space-factor-section: 3; --ft-space-factor-hero: 4.5; /* Layout */ --ft-container: min(var(--container-7xl), 90%); --ft-padding-content-x: 1rem; --ft-padding-content-y: var(--spacing-section); --ft-gap-content: var(--spacing-block); /* Colors */ --ft-color-text: #000; --ft-color-background: #f9ecec; /* Card widths */ --ft-card-xs: 12rem; /* 192px */ --ft-card-sm: 14rem; /* 224px */ --ft-card-md: 18rem; /* 288px */ --ft-card-lg: 24rem; /* 384px */ --ft-card-xl: 36rem; /* 576px */
