Buttons

Clase base .btn + variantes de color, tamano, forma y layout.

Variantes de color

<button class="btn btn-light">Light</button> <button class="btn btn-dark">Dark</button> <button class="btn btn-primary">Primary</button> <button class="btn btn-secondary">Secondary</button> <button class="btn btn-outline">Outline</button> <button class="btn btn-link">Link &rarr;</button>

Tamanos

<button class="btn btn-primary btn-xs">Extra Small</button> <button class="btn btn-primary btn-sm">Small</button> <button class="btn btn-primary">Default</button> <button class="btn btn-primary btn-lg">Large</button> <button class="btn btn-primary btn-xl">Extra Large</button>

Formas

<button class="btn btn-primary">Default</button> <button class="btn btn-primary btn-rounded">Rounded</button> <button class="btn btn-primary btn-circle">A</button> <button class="btn btn-primary btn-wide">Wide</button>

Full width

<button class="btn btn-primary btn-block">Block Button</button>

Combinaciones

<button class="btn btn-outline btn-rounded btn-lg">Outline + Rounded + LG</button> <button class="btn btn-dark btn-sm btn-wide">Dark + SM + Wide</button> <button class="btn btn-secondary btn-rounded btn-xs">Secondary + Rounded + XS</button>

Submit (auto-estilizado)

button[type="submit"] recibe estilo automaticamente sin necesidad de clase .btn.

<!-- Sin clase .btn — se estiliza solo --> <button type="submit">Enviar formulario</button>

Variables CSS de configuracion

:root { --btn-py: 0.6em; /* Padding vertical */ --btn-px: 1.75em; /* Padding horizontal */ --btn-primary-color: #f5f5f5; /* Texto sobre primary */ --btn-secondary-color: #f5f5f5;/* Texto sobre secondary */ --btn-outline-bg: transparent; --btn-outline-border: currentColor; --btn-outline-color: #262626; }
