Text (body)

.text-largetext-lg, leading-snug

Texto grande para destacar del cuerpo principal. Ideal para introducciones o llamadas de atencion.

.text-mediumtext-base, leading-normal

Texto base para la mayoria del contenido. Tamano por defecto del body.

.text-smalltext-sm, leading-relaxed

Texto pequeno para informacion de apoyo, notas al pie o metadata.

<p class="text-large">Intro o destacado</p> <p class="text-medium">Contenido base</p> <p class="text-small">Notas o metadata</p>
